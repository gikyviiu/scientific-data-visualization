# Системы научной визуализации данных

## Содержание 
 1. Построение аналитических функций
 2. Обработка табличных данных
 3. Оформление графиков в Gnuplot
 4. Визуализация скалярных и векторных полей в Gnuplot
 5. Визуализация потенциальных векторных полей
 6. Визуализация скалярных полей методом маркированных квадратов
 7. Построение силовых линий векторного поля
 8. Использование программы SciDAVis
 9. Построение графиков в SciDAVis
 10. Библиотека Matplotlib
 11. Воксельная графика

## Используемые технологии и инструменты

- **Gnuplot** - построение графиков и визуализация данных
- **Python 3** - программирование и анализ данных
  - Matplotlib - библиотека для визуализации
  - NumPy - работа с числовыми данными
- **SciDAVis** - интерактивная научная визуализация
- **Jupyter Notebook** - интерактивные вычисления
